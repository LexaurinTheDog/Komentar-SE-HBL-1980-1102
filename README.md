# Kommentar till lagen (1980:1102) om handelsbolag och enkla bolag

Kommentar till svensk författning: **Lag (1980:1102) om handelsbolag och enkla bolag** (SFS 1980:1102). Kommentaren omfattar **80 enheter** (72 paragrafer i 1–4 kap., inklusive 1 kap. 2 a § samt 2 kap. 3 a och 22 a §§, och övergångsbestämmelserna till åtta författningar) fördelade på 3 kommentarskapitel; vid varje enhet återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2018:1662** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=1980:1102](https://rkrattsbaser.gov.se/sfst?bet=1980%3A1102) · [data.riksdagen.se/dokument/sfs-1980-1102](https://data.riksdagen.se/dokument/sfs-1980-1102.json)
